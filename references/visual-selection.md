# 展示方式、图表与图标选择优化

## 资源边界

所有已选资源都在同一份 `assets/reference.pptx` 中。原公司模板是第1–56页；新增48种展示方式为第57–104页（R001–R048）；新增5张图标素材页为第105–109页（432个对象，其中336个原生形状、96个图片对象，不代表432种互不重复的语义）。精确页码、原生形状ID、可编辑类型、来源和适用条件见 `references/visual-resources.json`。

基础版式、封面、目录、章节、结束页仍按原模板执行。新增页面只提供正文展示结构和图标，不引入外部模板的母版、封面或目录规则。第56页仍是结束页；不能把参考文件最后一页当结束页。

## 先分析内容，再选形式

1. 提取用户提供的信息关系：事件顺序、持续时间、并行、依赖、层级、比较、组成、交集或定量趋势。
2. 核对要素数量、正文长度、是否需要日期刻度、是否有真实数据。先确定横向/纵向约束，不因示例有5节点而编造第5项。
3. 用索引筛出2–3个候选，查看对应预览并说明选择理由。内容密度、读序和语义优先于装饰复杂度；用户只要一个版本时，不必交付所有候选。
4. 合适时复用原生结构；不合适时制作简洁的新可编辑图形，沿用公司色、字体、页眉及真实标题占位符。可以删减或扩展正文节点，但不得改动母版或强行压小文字。

| 信息关系 | 优先资源 | 使用条件与限制 |
| --- | --- | --- |
| 完成日期、里程碑 | R007、R008；必要时R009 | 等距节点表示事件顺序，不表示相同时间跨度；如需要真实时间距离，按日期定位 |
| 任务起止与持续时间 | R001–R005 | 有真实起止日期才用甘特；统一刻度、条长与日期，不把完成日期反推开始日期 |
| 时间、部门与任务 | R006、R015 | 真实存在分工或并行；泳道的归属和读序必须明确 |
| 线性步骤、阶段交付物 | R013、R014、R018、R019 | 阶梯高度不表示进度或优劣，除非内容确有该含义；顺序与依赖真实一致 |
| 并行分支、汇聚 | R011、R016、R031 | 只有真实分支或共同汇入时使用，不能将顺序流程画成并行 |
| 反馈闭环 | R017 | 最后一步确实回到起点；没有反馈关系不用圆环 |
| 原因分类、问题分析 | R020、R021 | 鱼骨用于分类，不将假设包装成已证明的因果关系 |
| 并列要点、中心主题 | R024–R026、R039、原第6/10页 | 匹配节点数与文本长度；中心连接不等于因果箭头 |
| 问题与措施、过去与未来 | R027、R029、R036 | 两侧项目一一对应时明确对齐，不暗示不存在的对应关系 |
| 共同要素、交集 | R028、R033 | 交叠区域必须有真实共享含义；面积不代表数量 |
| 递进、演进、层级 | R030、R034、R035、R040 | 层级及方向必须真实；金字塔面积不暗示人数/比例；层数按实际调整 |
| 输入与输出、筛选阶段 | R037、R038 | 漏斗只是阶段示意时明确非比例；真实转化率需用对应数字与正确比例 |
| 优势/劣势/机会/威胁 | R041 | 仅用于实际SWOT分析，不将任意四点塞入四象限 |
| 两个核心及支撑 | R042 | 真正的两个核心对象及支撑关系 |
| 构成、类别比较、趋势 | R043–R048、原第46–49页 | 必须有实际数据；更新嵌入工作簿、公式范围、缓存、图例、单位及文字注释 |

例如：用户只给“9月15日提取质控、16日预文库、17日捕获终文库、18日测序、22日分析”五个完成日期时，优先R007横向五节点时间轴。保留日期标签，注明等距展示不代表等时长；不能未经用户提供起始时间就改用甘特，也不能把18–22日画成与15–16日相同的实际时长。

## 定量图表选择与数据约束

- 类别比较优先柱状/条形；长标签和排序优先横向条形。柱/条的量轴通常从零开始，负值有明确零基线。
- 连续时间趋势可用折线；类别没有时间顺序时不要用连接线制造趋势。
- 饼/环仅用于互斥、穷尽的整体构成，单位与分母一致；不以环形图展示互不相加的指标。类别太多时用条形。
- 增减变化、进度条、百分比、甘特条必须与数值一致；示例中条长和数字可能不一致，调用时重新计算，不能只改标签。
- 避免直接沿用示例的3D效果、错误图例、趋势线或不必要的双轴；当这些会误导时重建公司色的2D原生图表。
- 示例数字、年份、引用及业务名称不是证据。实际输出中必须全部替换或删除；不能把示例数据当成项目数据。
- 原第46/48/49页含历史图表结构（缺省类别或稀疏缓存），严格图表验证器可能不支持。参考库保留原生结构，不为通过检查凭空补零、改工作簿或栅格化。引用为成品时，用用户真实数据重建/更新完整数据源并重新验证；不能直接宣称这些示例的数据合同已通过。

## 图标选择优化

1. 先选与动作或对象直接相关的图标，例如日历表示日期、文件表示交付物、数据库表示数据存储。不能用购物篮表示核酸提取等无关实验动作。
2. 同页使用同一风格（线框或实心）、相近视觉重量和统一尺寸；看实际视觉边界，不仅比较外接矩形。优先原生可编辑形状，图片素材仍是图片，不宣称可编辑路径。
3. 品牌图标有29个对象，默认排除。只有内容明确涉及对应品牌且用途有授权时使用，不作为一般装饰。资源检索需显式 `-IncludeBrands` 才返回它们。
4. 标准化着色沿用公司蓝/青绿；警示红仅用于真实警示。图标不能作为医学结论、突变状态或检测结果的证据。
5. 没有合适图标时，使用文字标签、简单编号或自建可编辑示意图；不要为了使用资源库而强行添加。
6. 复制对象时保留组合和图片关系；重新定位新正文素材时不要拆解原模板的Logo/装饰组合。按 `NativeShapeId` 定位同一页的对象，而非按显示名称猜测。

## 查找与调用

在技能目录中运行（中文文件显式UTF-8读取）：

```powershell
pwsh.exe -NoLogo -NoProfile -File scripts/Get-MygeneVisualResource.ps1 -Kind method -Query 时间轴
pwsh.exe -NoLogo -NoProfile -File scripts/Get-MygeneVisualResource.ps1 -Id R007
pwsh.exe -NoLogo -NoProfile -File scripts/Get-MygeneVisualResource.ps1 -Kind icon -Query 日历 -Limit 8
pwsh.exe -NoLogo -NoProfile -File scripts/Get-MygeneVisualResource.ps1 -Kind icon -Style 线框 -EditableOnly -Limit 8
```

图标结果优先列出原生可编辑形状，可按Style与EditableOnly进一步过滤。选择器按实际信息匹配，不把索引中的推荐当强制规则。资源预览位于 `assets/resource-previews/`，不是另一份PPT资源库。

下例以原封面、目录、章节1、新R007和原结束页生成5页草稿：

```powershell
& ./scripts/Export-MygeneReferencePages.ps1 -Page 2,4,5,63,56 -OutputPath 'D:\工作目录\草稿.pptx'
```

该脚本只选页，不负责填充内容或自动决定章节。保留完整依赖以避免复杂图形损坏；未选页的ZIP部件可能保留，但不会成为活动页。重复页需要另行克隆slide部件并分配新关系ID，脚本会拒绝重复页码。随后修改原生文本/数据、替换无关图标、删除空目录项目及示例占位文本，完成结构验证与PowerPoint原生渲染检查后才能交付。

## 制作与验收检查

- 普通标题放入 `p:ph type="title"`，其 `p:spPr`、`a:lstStyle` 为空，段落/文字运行不覆盖字号、字体、颜色等母版样式。
- 表格保持原生网格，检查行高、列宽与文字留白；长文字优先改布局或分页，不任意缩至不可读。
- 旋转图形、组合变换和连接线按最终视觉边界检查，不能只用未旋转矩形判定越界；保持层级和读序。
- 调用后检查实际数据与文本一一对应、正确单位、箭头方向、节点数量、图标语义、色彩一致性、无示例残留。
- 检验器遍历活动页关系，不按 `slide数字.xml` 文件名假定页码；新增页使用 `vr_business_` / `vr_icons_` 部件名。
- 模板更新与成品验收区别对待：参考库允许明确标注的示例内容；成品必须用真实数据并通过相应图表验证。

## 与突变位点选择的边界

本资源选择优化针对PPT展示形式、图表和图标，不是肿瘤检测突变位点筛选或临床报告规则。若用户确实要求后者，应先确认Panel、用途和证据标准，再另行整理专业规则；不得由图形或配色推断突变阳性/阴性。
